以下是关于Kotlin中控制流关键字的简洁总结，结合你提供的代码示例：

1. 标签（Label）与 break/return ​

  • Kotlin允许通过标签精准控制跳转位置，解决嵌套循环的直接跳出问题。
  • 任何表达式都可以用标签来标记
  • 标签的格式为标识符后跟@符号,如：abc@、fooBar@

示例：带标签的 break ​

kotlin
loop@ for (i in 1..3) {          // 定义标签"loop@"
    for (j in 1..3) {
        if (j == 2) break@loop   // 直接跳出外层循环（到标签处）
        println("i=$i, j=$j")
    }
}

输出：

i=1, j=1
  • 当 j==2 时，break@loop 直接终止外层循环（而非仅内层），避免冗余嵌套判断。

2. 其他常用控制关键字 ​

(1) break（无标签） ​

直接终止当前所在的最内层循环：

kotlin
for (i in 1..3) {
    if (i == 2) break          // 仅跳出当前循环
    println(i)
}

输出：

1

(2) continue ​

跳过当前迭代，继续下一次循环：

kotlin
for (i in 1..3) {
    if (i == 2) continue       // 跳过i=2的这次循环
    println(i)
}

输出：

1
3

(3) return ​

从函数中直接返回，可结合标签实现从嵌套结构中返回：

kotlin
fun test() {
    loop@ for (i in 1..3) {
        for (j in 1..3) {
            if (j == 2) return@loop  // 从标签处继续执行（类似continue@loop）
            println("i=$i, j=$j")
        }
    }
    println("这行不会执行")       // 因return@loop会跳过后续代码
}

注意：return@loop 实际是从当前lambda或函数中返回，若在普通循环中需用 continue@loop。你的原始代码中的 break@loop 是正确的跳出循环用法。

3. 关键区别 ​

关键字作用范围行为
break终止循环直接退出当前或标签指定的循环
continue跳过当前迭代进入下一次循环
return退出函数/lambda可结合标签从嵌套结构中返回

4. 使用场景建议 ​

  • 嵌套循环跳出：优先用带标签的 break/continue，避免多层 if 判断。
  • 函数提前返回：用 return 或带标签的 return@label 从深层逻辑中快速退出。

通过标签机制，Kotlin提供了比传统 goto 更安全的流程控制能力。

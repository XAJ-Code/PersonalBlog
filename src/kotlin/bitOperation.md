# Kotlin 位运算详解

Kotlin 提供了一套完整的位运算操作符，用于直接操作整数的二进制位。这些运算在底层编程、性能优化和位掩码操作中非常有用。

## 1. 基本位运算

### 1.1 `and` (按位与)

**功能**：两个操作数的对应位都为 1 时，结果的该位才为 1，否则为 0。

**语法**：`a and b`

**示例**：
```kotlin
val a = 0b1100  // 12
val b = 0b1010  // 10
val result = a and b  // 0b1000 (8)
println(result)  // 输出: 8
```
**应用场景**：
- 提取特定位
- 掩码操作

### 1.2 `or` (按位或)

**功能**：两个操作数的对应位只要有一个为 1，结果的该位就为 1。

**语法**：`a or b`

**示例**：
```kotlin
val a = 0b1100  // 12
val b = 0b1010  // 10
val result = a or b  // 0b1110 (14)
println(result)  // 输出: 14
```
**应用场景**：
- 设置特定位为 1
- 合并位标志

### 1.3 `xor` (按位异或)

**功能**：两个操作数的对应位相同时，结果的该位为 0，否则为 1。(相同为 0，不同为 1)
**语法**：`a xor b`

**示例**：
```kotlin
val a = 0b1100  // 12
val b = 0b1010  // 10
val result = a xor b  // 0b0110 (6)
println(result)  // 输出: 6
```
**特性:**
- 相同数异或结果为 0：a xor a = 0
- 与 0 异或保持原值：a xor 0 = a
- 可逆性：(a xor b) xor b = a

**应用场景**：
- 交换两个变量(不使用临时变量)
- 与 1 做异或，可以取反
- 切换特定位(0变1，1变0)
- 简单加密

### 1.4 `inv` (按位取反)

**功能**：操作数的每一位都取反。(0 变 1，1 变 0)

**语法**：`inv(a)`

**示例**：
```kotlin
val a = 0b1100  // 12
val result = inv(a)  // 0b0011 注意：这是按位取反，不是数学上的负数
println(result)  // 输出: 3(因为Kotlin使用补码表示负数)
```
**重要说明**：
- 在 Kotlin 中，Int 是 32 位有符号整数，使用补码表示。
- 由于 Kotlin 使用补码表示负数，所以 -1 的二进制表示为 11111111111111111111111111111111，即 0xFFFFFFFF。
- inv(12) 的实际计算：
  . 12 的二进制：000...0001100 (32位)
  . 取反后：111...1110011 (这是 -13 的补码表示)

**应用场景**：
- 位掩码反转
- 特殊位操作

## 2. 位移运算
### 2.1 `shl` (左移)

**功能**：将操作数的二进制位向左移动指定位数，右侧空出的位补 0.

**语法**：`a shl n`

**示例**：
```kotlin
val a = 0b0001  // 1
val result = a shl 2  // 0b0100 (4)
println(result)  // 输出: 4
```
- 数学意义​​：相当于乘以 2ⁿ

**应用场景**：
- 乘以 2 的幂

### 2.2 `shr` (右移)

**功能**：将操作数的二进制位向右移动指定位数，左侧空出的位补符号位(算术右移)。

**语法**：`a shr n`

**示例**：
```kotlin
val a = 0b1111  // -1
val result = a shr 2  // 0b11111111111111111111111111111101 (0xFFFFFFFD)
println(result)  // 输出: -3

val a = 0b1000  // 8
val result = a shr 2  // 0b0010 (2)
println(result)  // 输出: 2
```
- 数学意义​​：相当于除以 2ⁿ(向下取整)

### 2.3 `ushr` (无符号右移)

**功能**：将操作数的二进制位向右移动指定位数，左侧空出的位补 0.

**语法**：`a ushr n`

**示例**：
```kotlin
val a = 0b1000  // 8
val result = a ushr 2  // 0b0010 (2)
println(result)  // 输出: 2

val b = 0b1100_0000_0000_0000_0000_0000_0000_0000  // -805306368 (补码表示)
val result2 = b ushr 2  // 0b0011_0000_0000_0000_0000_0000_0000_0000 (负数右移)
println(result2)  // 输出: -201326592
```
**与 `shr` 的区别**：
- `shr` 是算术右移,保留符号位
- `ushr` 是无符号右移,左侧空出的位补 0.不保留符号位

## 3.位运算应用示例

### 3.1 位掩码操作
```kotlin
// 定义标志位
const val FLAG_A = 0b0001
const val FLAG_B = 0b0010
const val FLAG_C = 0b0100
const val FLAG_D = 0b1000

// 设置标志位
var flags = 0
flags = flags or FLAG_A  // 设置FLAG_A
flags = flags or FLAG_C  // 设置FLAG_C

// 检查标志位
if (flags and FLAG_A != 0) {
    println("FLAG_A is set")
}

// 清除标志位
flags = flags and FLAG_A.inv()  // 清除FLAG_A

// 切换标志位
flags = flags xor FLAG_B  // 切换FLAG_B状态
```

### 3.2 颜色操作示例
```kotlin
// ARGB颜色表示(32位)
// A: 8位, R: 8位, G: 8位, B: 8位

// 提取红色分量
fun getRed(color: Int): Int {
    return (color shr 16) and 0xFF
}

// 设置红色分量
fun setRed(color: Int, red: Int): Int {
    return (color and 0xFF00FFFF) or (red shl 16)
}

// 示例使用
val color = 0xFFAABBCC
val red = getRed(color)  // 获取红色分量(AA)
val newColor = setRed(color, 0xFF)  // 设置红色分量为FF
```

## 4.注意事项
### 4.1 ​​Kotlin 的整数类型​​：
        - Int: 32位有符号整数
        - Long: 64位有符号整数
        - 位运算结果类型与操作数类型相同
### 4.2 补码表示：
        - Kotlin 使用补码表示负数
        - inv操作的结果可能与直观理解不同
### 4.3 位运算符优先级：
        - 位运算符优先级低于算术运算符
### 4.4 位移溢出​​：
        - 位移位数超过类型位数时，实际移动位数会取模
        - 例如 1 shl 33 在 Int 中相当于 1 shl 1 (因为 33 % 32 = 1)

## 5.总结表格
| 运算符 | 名称     | 描述                             | 示例                                      |
|--------|----------|----------------------------------|-------------------------------------------|
| `and`  | 按位与   | 两位都为1时结果为1               | `0b1100 and 0b1010 = 0b1000`              |
| `or`   | 按位或   | 两位有一个为1时结果为1           | `0b1100 or 0b1010 = 0b1110`               |
| `xor`  | 按位异或 | 两位不同时结果为1                | `0b1100 xor 0b1010 = 0b0110`              |
| `inv`  | 按位取反 | 所有位取反                       | `inv(0b1100) = 0b0011` (结果为 -13)       |
| `shl`  | 左移     | 位向左移动，右侧补0              | `0b0001 shl 2 = 0b0100` (相当于 1 × 4)    |
| `shr`  | 右移     | 位向右移动，左侧补符号位         | `0b1000 shr 2 = 0b0010` (相当于 8 ÷ 4)    |
| `ushr` | 无符号右移 | 位向右移动，左侧补0          | `0b1000 ushr 2 = 0b0010` (逻辑右移)       |

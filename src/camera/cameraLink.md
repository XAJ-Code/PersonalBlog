# 一、工业相机从传感器到上位机的信号链流程图
1. Camera Link是由AIA（Automated Imaging Association）制定的工业相机接口标准，面向高速、低时延的图像传输，采用LVDS并行传输并定义了统一的物理连接器与线缆。标准包含Base/Medium/Full三档配置：Base使用4个数据通道，Medium使用8个，Full使用12个；在85 MHz像素时钟下，Base约2.0 Gbps、Medium约4.8 Gbps、Full约5.4 Gbps（约680 MB/s）。规范还包含一条双向串行通信通道用于相机参数配置与控制。Camera Link通常需配合帧采集卡（Frame Grabber）使用，典型线缆长度< 10 m

2. Camera Link使用LVDS并行差分信号与专用线缆/连接器（如MDR‑26/SDR‑26），可实现高速、低时延的图像传输，并支持双向串行通信。

## **📊 工业相机信号链流程图**

```
+---------------------------+
|      被测物体 (光照)        |
+---------------------------+
            ↓
+---------------------------+
|  工业相机 — Image Sensor   |  ←【传感器】
|  (CCD / CMOS 感光阵列)      |
|  - 分辨率 (如 8K 线阵)       |
|  - 位深 (8/10/12/14bit)     |
|  - 全局/卷帘快门             |
+---------------------------+
            ↓
+---------------------------+
|   传感器输出 RAW 数据       |  (可能是 Bayer / Mono)
|   → 送入机内 ISP 或直出     |
+---------------------------+
            ↓
          【ISP】(可选)
    - 去马赛克 / 3A / 色彩校正
    - Gamma / 锐化 / 去噪
    - 输出 YUV / RGB / RAW
            ↓
+---------------------------+
|      相机接口层            |
|  ┌─────────────────────┐  |
|  │ GigE Vision         │ → RJ45 / 网口（无需采集卡）|
|  │ USB3 Vision         │ → USB3（无需采集卡）  |
|  │ Camera Link         │ → LVDS 差分信号【差分信号】|
|  │ CoaXPress (CXP)     │ → 同轴差分信号【差分信号】|
|  └─────────────────────┘  |
+---------------------------+
            ↓
   【是否需要采集卡？】
   ✅ Camera Link / CXP → 必须 PCIe 采集卡
   ❌ GigE / USB3 → 网卡/USB控制器即采集功能
            ↓
+---------------------------+
|   图像采集卡 (Frame Grabber)|
|  - PCIe 高速总线传输        |
|  - DMA 零拷贝搬运           |
|  - 硬件触发 & 同步 I/O      |
|  - 缓存 & FPGA 预处理       |
|  - PoCL / PoCXP 供电        |
+---------------------------+
            ↓
+---------------------------+
|   上位机 (PC / 工控机)      |
|  - CPU / GPU / FPGA 处理    |
|  - 算法 (检测/测量/识别)    |
|  - 显示 / 存储 / 通信       |
+---------------------------+

--- 线阵相机特有参数 ---
行频 (Line Rate)：每秒采集的行数 [Hz/kHz]  ←【行频】
最高行频：相机 & 接口能保证不丢数据的最大行频 ←【最高行频】
```

### **🔍 各模块作用与关联说明**
1. **传感器**  
   - 将光信号转为电信号（RAW数据）。  
   - 决定分辨率、位深、快门类型、感光能力。  

2. **ISP（可选）**  
   - 若在相机内完成：输出可直接使用的 RGB/YUV。  
   - 若直出 RAW：需在上位机/嵌入式平台完成 ISP。  

3. **差分信号**（Camera Link / CXP）  
   - 用 LVDS 或同轴差分传输高速数据，抗干扰强、适合短距离高带宽。  
   - 必须通过采集卡转成 PCIe 数据进主机。  

4. **行频 & 最高行频**  
   - 线阵相机每秒输出的行数。  
   - 最高行频受传感器读取速度、接口带宽、采集卡缓存限制。  
   - 选型时要保证**需求行频 ≤ 最高行频**。  

5. **采集卡**  
   - 在 Camera Link / CXP 场景下必不可少。  
   - 提供高速 DMA、硬件触发、同步 I/O、PoCL/PoCXP 供电。  
   - 对 GigE/USB3 相机则不需要额外采集卡（网卡/USB控制器代替）。  

6. **上位机**  
   - 运行视觉算法、显示与存储图像。  
   - 如果是 RAW 数据，这里还要跑 ISP 管线。  

---

### **🎯 结合你之前的埃科采集卡与相机**
- 如果你的相机是 **CXP 接口**（如埃科 Vulcan-CXP 系列），那么流程中：
  - 相机 → 同轴差分信号 → 埃科采集卡 → PCIe → 上位机。  
  - 行频/最高行频要匹配采集卡的单通道带宽（CXP-6 ≈ 625 MB/s，CXP-12 ≈ 1250 MB/s）。  
  - 采集卡还负责触发同步、PoCXP 供电、多相机拓扑管理。  

- 如果是 **GigE 相机**：流程中相机 → RJ45 → 网卡 → 上位机，无需埃科采集卡，行频概念变为帧频。  

---

这样一张图就把**传感器 → ISP → 接口（差分信号） → 采集卡 → 上位机**全串起来了，并且标出了**行频 / 最高行频**的位置，方便你在选型与调试时对照检查。

## 二、Camera Link 的 Base 与 Medium 配置

**核心概念与带宽**
- **Base**：单线缆（**1×MDR**），每帧携带**24位**图像数据，最大像素时钟**85 MHz**，理论吞吐约**255 MB/s**。适合中低分辨率或中帧率应用。  
- **Medium**：双线缆（**2×MDR**），每帧携带**48位**图像数据，最大像素时钟**85 MHz**，理论吞吐约**510 MB/s**。适合更高分辨率/更高行频/更高帧率场景。  
- 计算方式：**吞吐量（MB/s）**= 像素时钟（MHz）× 数据位数 ÷ 8。上述数值为标准定义的理论上限，实际可用有效带宽会因协议开销、同步与采集卡实现而略低。 

**端口与芯片构成**
- **Base**：占用**A/B/C**三个端口，使用**1**个 Channel Link 芯片，提供**24位**视频数据通道。  
- **Medium**：在 Base 基础上再加**1**个 Channel Link 基本单元，使用**A–F**共六个端口，提供**48位**视频数据通道。  
- 说明：两种配置在连接器与线缆规范上保持统一，差异主要体现在占用的端口数量与并行数据位宽。 

**线缆与采集卡要求**
- **Base**：**1 根 MDR 电缆**，需支持 Base 的**帧采集卡**（Frame Grabber）。  
- **Medium**：**2 根 MDR 电缆**，需支持 Medium/Full 的采集卡（通常同一块卡可覆盖 Base/Medium/Full）。  
- 采集卡需与相机的配置匹配（端口数、位宽与时钟能力）才能满速工作。 

**选型与带宽速算**
- 速算公式：所需配置 ≥ 图像数据率（MB/s）。其中**图像数据率** = 分辨率（像素/行 × 行/帧）× 位深（bit）÷ 8 ÷ 帧率（fps）。  
- 示例：  
  - **4K（4096×2160）@ 12bit @ 60fps** → 数据率 ≈ **756 MB/s**，需 **Medium/Full**。  
  - **2K（2048×1080）@ 8bit @ 120fps** → 数据率 ≈ **317 MB/s**，**Base**在理论上限附近，建议用 **Medium** 留余量。  
- 工程建议：在理论值基础上预留**20–30%**带宽余量，以应对协议开销、触发抖动与采集卡缓存调度。

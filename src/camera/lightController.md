# 光源控制器概念

## 一、网络通信设置

### 1. IP地址配置
**问题场景**：计算机IP为`169.254.120.220`，光源控制器IP为`192.168.0.208`

#### 解决方案：
```bash
# 方案1：修改计算机IP（推荐）
IP地址: 192.168.0.100
子网掩码: 255.255.255.0
网关: 192.168.0.1

# 方案2：修改控制器IP
控制器IP: 169.254.120.221
子网掩码: 255.255.0.0
网关: 留空或0.0.0.0
```

#### 网络诊断命令：
```bash
ipconfig /release    # 释放当前IP
ipconfig /renew      # 重新获取IP
ping 192.168.0.208   # 测试连通性
```

## 二、核心控制参数

### 1. 行频（Frequency）
**定义**：单位时间内光源闪烁的次数
- **单位**：Hz（赫兹）
- **作用**：控制闪烁速度，与相机帧率同步
- **范围**：通常1Hz-10kHz可调

### 2. 脉宽（Pulse Width）
**定义**：每次闪烁持续的时长
- **单位**：μs（微秒）
- **作用**：控制单次点亮时间，影响亮度
- **范围**：通常1μs-999μs可调

### 3. 行频与脉宽的关系
```csharp
// 示例设置
行频 = 1000Hz;    // 每秒闪烁1000次
脉宽 = 200μs;     // 每次点亮200微秒

// 亮度影响：
// - 行频固定：脉宽↑ → 亮度↑
// - 脉宽固定：行频↑ → 亮度↑
```

## 三、分倍频参数

### 1. 基本概念
- **分频**：降低频率，输出频率 = 输入频率 ÷ N
- **倍频**：提高频率，输出频率 = 输入频率 × M

### 2. 应用示例
```csharp
// 分频应用（降速）
输入频率: 1000Hz → 分频系数4 → 输出频率: 250Hz

// 倍频应用（提速）  
输入频率: 1000Hz → 倍频系数4 → 输出频率: 4000Hz
```

### 3. 技术实现
- **分频**：简单计数器电路
- **倍频**：PLL锁相环技术
- **系数**：通常为2、4、8、16等整数倍

## 四、参数配置指南

### 1. 不同应用场景推荐设置

| 应用场景 | 行频范围 | 脉宽范围 | 说明 |
|---------|---------|---------|------|
| 高速运动检测 | 1-10kHz | 10-100μs | 需要快速响应 |
| 一般工业检测 | 50-500Hz | 100-500μs | 平衡亮度与速度 |
| 静态物体检测 | 1-50Hz | 500-1000μs | 注重图像质量 |

### 2. 同步性设置要点
```csharp
// 正确的同步设置
光源行频 = 相机帧率 × N（N为整数）
曝光时间 = 脉宽 + 安全余量
触发延迟 < 2μs（确保精确同步）
```

## 五、故障排查指南

### 1. 网络连接问题
**症状**：IP地址为169.254.x.x
**解决方案**：
1. 检查网线物理连接
2. 重启路由器/交换机
3. 手动设置静态IP
4. 更新网络适配器驱动

### 2. 控制参数异常
**症状**：图像闪烁、亮度不均
**解决方案**：
1. 检查行频与相机帧率同步
2. 调整脉宽匹配曝光时间
3. 验证分倍频系数设置
4. 检查触发信号稳定性

## 六、最佳实践建议

### 1. 参数优化流程
1. **基础设置**：先设置较低行频和适中脉宽
2. **同步测试**：确保与相机触发同步
3. **亮度优化**：调整脉宽获得最佳图像质量
4. **频率优化**：根据运动速度调整行频
5. **稳定性测试**：长时间运行验证参数稳定性

### 2. 设备维护要点
- 定期检查网络连接稳定性
- 监控控制器温度，确保散热良好
- 备份成功的参数配置
- 及时更新控制器固件

## 七、技术联系表

| 参数类型 | 影响范围 | 调整优先级 | 注意事项 |
|---------|---------|----------|---------|
| 行频 | 同步性、运动模糊 | 高 | 必须与相机帧率同步 |
| 脉宽 | 亮度、图像质量 | 中 | 影响光源寿命 |
| 分倍频 | 触发精度 | 中 | 需要编码器信号支持 |
| IP地址 | 通信连接 | 高 | 确保网段一致 |

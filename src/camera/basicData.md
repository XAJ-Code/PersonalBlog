# 相机核心三要素：帧率、曝光与增益

## 💡 图片是如何诞生的

一张数字图片的诞生，可以概括为三个核心步骤：**光学成像、光电转换和信号处理**。

1.  **光学成像：镜头聚光**
    这个过程始于相机的镜头，它就像一只精密的“眼睛”。其核心作用是将外部场景反射的光线汇聚起来，在相机内部的图像传感器上形成一个清晰的、倒立的实像。镜头的质量，比如其光学设计、使用的镜片材质和镀膜工艺，直接决定了这个初始影像的清晰度、锐利度和是否会出现畸变或色散。

2.  **光电转换：传感器捕获光信号**
    光线抵达图像传感器（主要是**CMOS**或**CCD**）后，真正的魔法开始了。传感器上布满了数百万甚至上亿个微小的光敏元件（像素）。每个像素都是一个光电二极管，会将接收到的光子（光能量）转换成电子（电荷），电荷的多少与光线的强弱成正比。这个过程将**光信号**转变成了**模拟电信号**。

3.  **从模拟到数字：信号处理**
    传感器产生的模拟电信号需要被转换成计算机能识别的语言。这个过程由**模数转换器（ADC）** 完成，它将连续的模拟信号转换为离散的数字值（例如，一个12位的ADC会将光强度量化为0-4095之间的一个数值）。此时的数据被称为 **RAW数据**，它是最原始、未经任何修饰的传感器数据，每个像素只记录了一种颜色的亮度信息。最后，**图像信号处理器（ISP）** 会对RAW数据进行一系列复杂的处理，包括“去马赛克”以插值出每个像素完整的RGB颜色、进行白平衡校正、降噪、锐化等，最终生成一张我们可以直接观看的JPEG或PNG格式图片。

## 概述

帧率（Frame Rate）、曝光（Exposure）和增益（Gain/ISO）是视频与摄影中最基础、最核心的三个概念。理解它们各自的定义以及三者之间的制约关系，是掌握相机使用的第一步。

---

## 1. 曝光 (Exposure)

### 1.1 核心概念
曝光决定了画面的整体明暗程度。目标是获得“曝光正确”的图像，避免“过曝”（太亮，丢失亮部细节）或“欠曝”（太暗，丢失暗部细节）。

### 1.2 曝光三角
曝光由三个参数共同控制，它们像一个三角形的三条边，相互影响、相互制约。

| 参数 | 类比 | 作用 | 提高带来的影响 | 主要副作用 |
| :--- | :--- | :--- | :--- | :--- |
| **光圈 (Aperture)** | **水龙头阀门的大小** | 控制单位时间内的进光量 | 画面变亮 | **景深变浅**（背景虚化效果更强） |
| **快门速度 (Shutter Speed)** | **阀门打开的时间** | 控制感光元件感光的时间 | 画面变亮 | **运动模糊增加**（速度越慢，拖影越明显） |
| **感光度 (ISO / Gain)** | **工人的工作效率** | 放大传感器接收到的信号强度 | 画面变亮 | **噪点增加**（画质下降） |

### 1.3 如何平衡曝光三角
调整曝光的过程，就是在**画质**（低ISO）、**景深**（光圈）和**动态模糊**（快门）之间根据自己的创作需求进行取舍和平衡。

---

## 2. 帧率 (Frame Rate, FPS)

### 2.1 核心概念
帧率是指视频**每秒记录的静态画面（帧）的数量**，单位为 FPS (Frames Per Second)。帧率决定了视频画面的流畅度以及能否用于慢动作播放。

### 2.2 常见帧率及其应用
| 帧率 (FPS) | 主要应用场景 |
| :--- | :--- |
| **24 / 25** | 电影标准帧率，营造独特的“电影感” |
| **30** | 电视、网络视频常用帧率，比24/25帧更流畅 |
| **60 / 120 / 240+** | **高速帧率**，常用于拍摄运动场景、游戏视频，或用于制作**平滑的慢动作**效果 |

> **慢动作原理**：用高帧率（如60FPS）拍摄，以低帧率（如30FPS）播放，播放时间延长，从而实现慢放。60FPS → 30FPS播放 = 2倍慢放。

### 2.3 帧率与快门速度的关系（180°快门法则）
为了获得最自然流畅的动态模糊效果，视频拍摄中通常遵循一条经验法则：
**快门速度 ≈ 1 / (2 × 帧率)**

| 帧率 (FPS) | 推荐快门速度 |
| :--- | :--- |
| 24 | 1/50s |
| 30 | 1/60s |
| 60 | 1/120s |

**重要影响**：提高帧率（如从30FPS升至60FPS）意味着必须提高快门速度（从1/60s升至1/120s）。**快门速度提高，进光量减少，画面会变暗**。此时必须通过开大光圈或提高ISO来补偿曝光。

---

## 3. 增益 (Gain) / ISO

### 3.1 核心概念
增益（在专业摄像机中常用）和ISO（在消费级相机中常用）在数码领域**本质是相同的**。它指的是相机内部对图像传感器输出信号的**放大程度**。

### 3.2 工作原理与副作用
- **工作原理**：它并非提升传感器本身的感光能力，而是将捕获到的原始信号（包括有用的图像信号和固有的噪点信号）进行**电子放大**。
- **核心副作用**：**画质下降和噪点增加**。增益/ISO越高，画面中的彩色或黑白噪点（颗粒感）就越明显，细节和色彩纯净度下降。
- **使用策略**：**作为最后的手段**。优先使用光圈和快门控制曝光，只有在它们都无法满足需求时（如光圈已最大，快门已最慢），才提高增益/ISO。

---

## 4. 三者的联动与设置策略

### 4.1 相互关系总结
- **帧率** 决定了 **快门速度** 的基准值。
- **快门速度** 和 **光圈** 是控制曝光的主力，直接影响画质（模糊、景深）。
- **增益/ISO** 是补偿曝光的备用方案，会牺牲画质。

### 4.2 视频拍摄设置流程（推荐步骤）
1.  **定帧率**：根据创作意图（正常视频 or 慢动作）确定帧率（如 25FPS or 60FPS）。
2.  **定快门**：根据180°法则，设定快门速度（如 25FPS → 1/50s；60FPS → 1/120s）。
3.  **定光圈**：根据想要的景深（虚化程度）设定光圈值（想要虚化用大光圈，如f/2.8；想要全景清晰用小光圈，如f/8）。
4.  **调曝光**：观察画面亮度。
    - **如果画面太暗**：
        - 优先考虑开大光圈。
        - 如果光圈已到最大，可适当提高增益/ISO。
    - **如果画面太亮**：
        - 优先考虑缩小光圈。
        - 如果想保持大光圈虚化效果，必须使用 **ND减光镜**（中性密度镜）来物理减光。

---

## 5.焦距
### 5.1焦距的定义
- 焦距是镜头的光学中心到相机传感器的距离。
- 焦距越短，景深越浅，画面越清晰,**视角越大,拍摄的场景越大**。
- 焦距越长，景深越深，画面越模糊,**视角越窄,拍摄的场景越小,物体在图像显的更大**。

### 5.2变焦镜头和定焦镜头
- 定焦镜头：焦距固定，不随光圈变化。
- 变焦镜头：焦距可变，随光圈变化，手动切换到手动对焦(MF/M)。
- 一般都是以**mm**为单位。如23mm镜头，53mm镜头。35-50mm是变焦镜头。
- 拍摄运动物体一般使用自动对焦(AF)

## 总结

| 概念 | 它主要控制什么？ | 调整它的主要代价是什么？ |
| :--- | :--- | :--- |
| **帧率 (FPS)** | 流畅度与慢放能力 | 决定了快门速度，从而影响进光量 |
| **光圈 (Aperture)** | 景深（背景虚化程度） | 虚化效果或画面清晰范围 |
| **快门速度 (Shutter)** | 动态模糊（运动轨迹） | 运动物体的拖影或凝固程度 |
| **增益/ISO (Gain/ISO)** | 信号灵敏度（画面亮度） | **画质噪点** |


要理解模拟增益，我们可以把它想象成图像传感器（CMOS）在将光信号转换为电信号后，进行的一次**“源头放大”**。它发生在信号被转换成数字形式之前，直接作用于最原始的模拟电信号。

下面这个表格能帮你快速抓住模拟增益的核心要点，并与数字增益进行对比。

| 特性 | 模拟增益 (Analog Gain) | 数字增益 (Digital Gain) |
| :--- | :--- | :--- |
| **作用阶段** | **模数转换（ADC）之前**，对模拟电信号进行放大 | **模数转换（ADC）之后**，对数字信号进行放大 |
| **本质** | 通过硬件电路（如运算放大器）提升信号电压 | 通过软件算法对数字值进行乘法运算 |
| **关键影响** | **优先放大有用信号**，有助于提升信噪比（SNR） | **等比例放大所有信息**（包括信号和ADC引入的噪声），不改善信噪比 |
| **噪声表现** | 噪声相对自然，类似胶片颗粒感 | 容易放大不自然的、“脏”的数码噪点 |
| **灵活性** | 依赖硬件，调整范围相对有限 | 通过软件实现，非常灵活，调整范围广 |

### 💡 模拟增益的工作流程与优势

图像传感器成像可以简化为三个关键步骤：
1.  **光电转换**：像素点感应光子，产生微弱的电荷信号。
2.  **模拟增益放大**：这是模拟增益发挥作用的地方。它通过硬件放大器将这个微弱的原始电信号进行放大。
3.  **模数转换（ADC）**：将放大后的、稳定的模拟信号转换为数字信号，供后续处理。

模拟增益的核心优势在于它发生在ADC之前。这意味着，它放大的**是纯净的、未被数字量化噪声污染的有用信号**。这样，当信号通过ADC时，有用的信号强度相对于ADC自身产生的电路噪声和量化噪声就更强，从而有助于提升最终图像的信噪比（SNR）。你可以理解为，在杂质混入之前，先把有用的原料加固了。

### 🎯 如何在实际应用中设置增益？

在实际使用工业相机或调整摄像头参数时，有一个通用的**最佳实践顺序**，旨在尽可能获得最干净的画面：

1.  **优先调整曝光时间**：确保有足够的光线进入传感器，这是基础。
2.  **其次增加模拟增益**：当曝光时间达到上限（如因物体运动速度不能再长）仍感光不足时，优先使用模拟增益来提高亮度。
3.  **最后考虑数字增益**：只有当模拟增益调到最大仍无法满足亮度需求时，才谨慎使用数字增益作为补充。

这个顺序的核心思想是：**充分利用模拟增益在信噪比上的优势，将数字增益作为迫不得已的最后手段**，以最小化画面中不希望的噪声。

### 💎 总结

简单来说，**模拟增益是在图像信号数字化之前，通过硬件电路进行的一次“源头强化”**。它能有效提升信噪比，是图像质量优化中**优先于数字增益**的选择。

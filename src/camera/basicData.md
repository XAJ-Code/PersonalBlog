# 相机核心三要素：帧率、曝光与增益

## 概述

帧率（Frame Rate）、曝光（Exposure）和增益（Gain/ISO）是视频与摄影中最基础、最核心的三个概念。理解它们各自的定义以及三者之间的制约关系，是掌握相机使用的第一步。

---

## 1. 曝光 (Exposure)

### 1.1 核心概念
曝光决定了画面的整体明暗程度。目标是获得“曝光正确”的图像，避免“过曝”（太亮，丢失亮部细节）或“欠曝”（太暗，丢失暗部细节）。

### 1.2 曝光三角
曝光由三个参数共同控制，它们像一个三角形的三条边，相互影响、相互制约。

| 参数 | 类比 | 作用 | 提高带来的影响 | 主要副作用 |
| :--- | :--- | :--- | :--- | :--- |
| **光圈 (Aperture)** | **水龙头阀门的大小** | 控制单位时间内的进光量 | 画面变亮 | **景深变浅**（背景虚化效果更强） |
| **快门速度 (Shutter Speed)** | **阀门打开的时间** | 控制感光元件感光的时间 | 画面变亮 | **运动模糊增加**（速度越慢，拖影越明显） |
| **感光度 (ISO / Gain)** | **工人的工作效率** | 放大传感器接收到的信号强度 | 画面变亮 | **噪点增加**（画质下降） |

### 1.3 如何平衡曝光三角
调整曝光的过程，就是在**画质**（低ISO）、**景深**（光圈）和**动态模糊**（快门）之间根据自己的创作需求进行取舍和平衡。

---

## 2. 帧率 (Frame Rate, FPS)

### 2.1 核心概念
帧率是指视频**每秒记录的静态画面（帧）的数量**，单位为 FPS (Frames Per Second)。帧率决定了视频画面的流畅度以及能否用于慢动作播放。

### 2.2 常见帧率及其应用
| 帧率 (FPS) | 主要应用场景 |
| :--- | :--- |
| **24 / 25** | 电影标准帧率，营造独特的“电影感” |
| **30** | 电视、网络视频常用帧率，比24/25帧更流畅 |
| **60 / 120 / 240+** | **高速帧率**，常用于拍摄运动场景、游戏视频，或用于制作**平滑的慢动作**效果 |

> **慢动作原理**：用高帧率（如60FPS）拍摄，以低帧率（如30FPS）播放，播放时间延长，从而实现慢放。60FPS → 30FPS播放 = 2倍慢放。

### 2.3 帧率与快门速度的关系（180°快门法则）
为了获得最自然流畅的动态模糊效果，视频拍摄中通常遵循一条经验法则：
**快门速度 ≈ 1 / (2 × 帧率)**

| 帧率 (FPS) | 推荐快门速度 |
| :--- | :--- |
| 24 | 1/50s |
| 30 | 1/60s |
| 60 | 1/120s |

**重要影响**：提高帧率（如从30FPS升至60FPS）意味着必须提高快门速度（从1/60s升至1/120s）。**快门速度提高，进光量减少，画面会变暗**。此时必须通过开大光圈或提高ISO来补偿曝光。

---

## 3. 增益 (Gain) / ISO

### 3.1 核心概念
增益（在专业摄像机中常用）和ISO（在消费级相机中常用）在数码领域**本质是相同的**。它指的是相机内部对图像传感器输出信号的**放大程度**。

### 3.2 工作原理与副作用
- **工作原理**：它并非提升传感器本身的感光能力，而是将捕获到的原始信号（包括有用的图像信号和固有的噪点信号）进行**电子放大**。
- **核心副作用**：**画质下降和噪点增加**。增益/ISO越高，画面中的彩色或黑白噪点（颗粒感）就越明显，细节和色彩纯净度下降。
- **使用策略**：**作为最后的手段**。优先使用光圈和快门控制曝光，只有在它们都无法满足需求时（如光圈已最大，快门已最慢），才提高增益/ISO。

---

## 4. 三者的联动与设置策略

### 4.1 相互关系总结
- **帧率** 决定了 **快门速度** 的基准值。
- **快门速度** 和 **光圈** 是控制曝光的主力，直接影响画质（模糊、景深）。
- **增益/ISO** 是补偿曝光的备用方案，会牺牲画质。

### 4.2 视频拍摄设置流程（推荐步骤）
1.  **定帧率**：根据创作意图（正常视频 or 慢动作）确定帧率（如 25FPS or 60FPS）。
2.  **定快门**：根据180°法则，设定快门速度（如 25FPS → 1/50s；60FPS → 1/120s）。
3.  **定光圈**：根据想要的景深（虚化程度）设定光圈值（想要虚化用大光圈，如f/2.8；想要全景清晰用小光圈，如f/8）。
4.  **调曝光**：观察画面亮度。
    - **如果画面太暗**：
        - 优先考虑开大光圈。
        - 如果光圈已到最大，可适当提高增益/ISO。
    - **如果画面太亮**：
        - 优先考虑缩小光圈。
        - 如果想保持大光圈虚化效果，必须使用 **ND减光镜**（中性密度镜）来物理减光。

## 5.焦距
### 5.1焦距的定义
- 焦距是镜头的光学中心到相机传感器的距离。
- 焦距越短，景深越浅，画面越清晰,**视角越大,拍摄的场景越大**。
- 焦距越长，景深越深，画面越模糊,**视角越窄,拍摄的场景越小,物体在图像显的更大**。

### 5.2变焦镜头和定焦镜头
- 定焦镜头：焦距固定，不随光圈变化。
- 变焦镜头：焦距可变，随光圈变化，手动切换到手动对焦(MF/M)。
- 一般都是以**mm**为单位。如23mm镜头，53mm镜头。35-50mm是变焦镜头。
- 拍摄运动物体一般使用自动对焦(AF)

## 总结

| 概念 | 它主要控制什么？ | 调整它的主要代价是什么？ |
| :--- | :--- | :--- |
| **帧率 (FPS)** | 流畅度与慢放能力 | 决定了快门速度，从而影响进光量 |
| **光圈 (Aperture)** | 景深（背景虚化程度） | 虚化效果或画面清晰范围 |
| **快门速度 (Shutter)** | 动态模糊（运动轨迹） | 运动物体的拖影或凝固程度 |
| **增益/ISO (Gain/ISO)** | 信号灵敏度（画面亮度） | **画质噪点** |

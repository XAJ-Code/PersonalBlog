# 相机核心图像参数速查手册

## 概述
本文档旨在提炼关键图像参数的核心作用，助您快速理解并应用。所有处理均由相机ISP（图像信号处理器）完成。

---

## 参数核心作用一览

| 参数 | 核心作用 | 好比 | 调整建议 |
| :--- | :--- | :--- | :--- |
| **白平衡 (WB)** | **校正颜色偏差**，使白色在任何光线下都显白。 | 让照片脱掉“有色眼镜”（如偏黄、偏蓝）。 | **优先自动(AWB)**。偏色时，手动选择对应光源模式（如白炽灯图标）或对白纸校准。 |
| **饱和度 (Saturation)** | **控制颜色的鲜艳程度**。 | 调色盘的颜料纯度。越高越艳丽，越低越朴素。 | 适度增加(+1)让风光、食物更诱人。过度调整会色彩失真、缺乏层次。 |
| **锐度 (Sharpness)** | **增强边缘轮廓，提升清晰感**。 | 给图像“画边线”，让细节更突出。 | 适度增加(+1)让细节更清晰。过度调整会产生不自然白边和噪点。 |
| **色调 (Tone)** | **控制整体颜色倾向**（偏暖或偏冷）。 | 给整个画面统一叠加一层色纱（如偏黄或偏蓝）。 | 微调可营造氛围（如人像稍偏暖显肤色红润，风景稍偏冷显通透）。 |
| **伽马 (Gamma)** | **优化明暗对比与亮度层次**。 | 压缩亮部、提亮暗部，让照片告别“灰蒙蒙”。 | 通常默认即可。**LOG模式**即是大幅降低伽马以记录更多亮暗细节，供后期调整。 |

---

## 核心技术原理

### Bayer插值 (Demosaic)
- **作用**：将传感器捕获的**黑白马赛克（RAW）数据，“猜”出全彩图像**的核心算法。
- **须知**：这是RAW转JPG的第一步，所有后续调整都基于此。算法优劣直接影响细节和伪色（彩色条纹）。

## 实践应用举例

1.  **拍摄人像**
    - **白平衡**：稍向**暖调（+）** 调整，使肤色显得红润、健康。
    - **饱和度**：**适度（+1）**，让唇色和衣物颜色更自然好看。
    - **锐度**：**适度（+1）**，让发丝和眼部细节更清晰。
    - **目标**：打造自然、温馨、细节丰富的肖像。

2.  **拍摄风景**
    - **白平衡**：选择“日光”模式，或保持自动，还原真实色彩。
    - **饱和度**：可**适当提高（+1~2）**，让天空更蓝、植物更绿。
    - **锐度**：**直接提高（+2）**，让建筑物、树叶纹理更清晰。
    - **目标**：获得色彩鲜明、细节锐利的壮观画面。

3.  **拍摄食物**
    - **白平衡**：务必准确，避免食物看起来发黄（像变质）或发蓝（没食欲）。
    - **饱和度**：**适度提高（+1）**，让食物看起来更新鲜、诱人。
    - **色调**：可稍向**暖调（+）** 微调，增加温暖和食欲感。
    - **目标**：拍出令人垂涎欲滴的美食照片。

4.  **后期创作**
    - **色调**：大幅向**冷调（-）** 调整，可营造清冷、未来感或孤独氛围。
    - **饱和度**：**大幅降低**，可打造简约、冷淡或怀旧的风格。
    - **伽马**：拍摄**LOG/Flat模式**（低伽马），为后期调色保留最大亮暗信息。

---

## 核心关系总结

1.  **工作流程**：
    `Bayer插值` → `白平衡` → （`色调/饱和度`调整） → `锐化` → `伽马编码` → 输出JPG。

2.  **调整优先级**：
    **先调白平衡**确定色彩基准，再调饱和度/色调定义风格，最后用锐度增强细节。伽马通常保持默认。

3.  **黄金法则**：
    **宁缺毋滥**。所有参数的微调（±1）通常优于大幅调整，以保持画面的自然和真实感。
